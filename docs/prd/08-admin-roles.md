# PRD — Admin Roles
> Admin dashboard, manual sale entry, manager ROI, customization, user roles

## 34. Admin Dashboard

### User Management

- Add user
- Edit user
- Disable user
- Assign avatar
- Reset password

### KPI Configuration

- Monthly target
- Weekly target
- Daily target
- Calls
- Meetings
- Proposals
- Revenue
- Deals

### Reward Configuration

- XP weights
- Milestones
- Level unlocks
- Boss targets

### Branding

- Company name
- Logo
- Colors
- Office signage
- Character clothing

### Data Input

- Manual entry
- Generic webhook
- REST API
- CRM connections

### Reporting

- Revenue
- Activity
- Game engagement
- Last login
- Milestones
- Target progress

## 35. Manual Sale Entry

For businesses without CRM integration.

Fields:

- Deal amount
- Client name optional
- Date
- Deal type
- Notes

Optional approval:

**Player submits → manager approves → reward triggers**

## 49. Manager ROI Dashboard

Show:

- User engagement
- Target progress
- Sales activity
- Game usage
- Milestones
- Performance trend

Future feature:

**Before Sales Empire vs After Sales Empire**

This should be observational unless a controlled experiment exists.

## 50. Customer Customization

Each customer can customize:

- Company logo
- Company colors
- Avatar
- Shirt
- Office branding
- Currency
- KPI names
- Targets
- Rewards
- Rank names
- Boss names
- Building name

Example:

**SALIK BUILDS HQ**

instead of a generic building.

## 61. User Roles

### Admin

Can:

- Configure targets
- Manage user
- Approve manual events
- Configure branding
- View analytics
- Configure rewards
- Manage integrations

### Player

Can:

- View game
- View progress
- View achievements
- Customize unlocked cosmetics
- Submit manual performance events if enabled
